# Initial Cost Estimate

## 1. Coste por bloque funcional
- Entrada y normalización: 12k - 20k EUR
- Orquestación IA: 20k - 45k EUR
- Generador JSON: 18k - 35k EUR
- Integración GitHub: 12k - 25k EUR
- Integración Jira: 15k - 28k EUR
- Script Python automatización: 10k - 18k EUR

## 2. Coste por arquitectura
- Monolito API + Workers: 75k - 130k EUR
- Microservicios desacoplados: 130k - 220k EUR
- Serverless gestionado: 95k - 160k EUR

## 3. Coste de infraestructura
- Entorno inicial mensual: 500 - 2k EUR + consumo IA.

## 4. Coste de integraciones
- Seguridad, secretos, SSO y conectores extra: 10k - 40k EUR

## 5. Coste de mantenimiento anual
- Entre 15% y 22% del coste de implantación.
